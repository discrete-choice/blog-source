Check [documentation](https://hexo.io/docs/){target="_blank"
rel="noopener"} for more info. If you get any problems when using Hexo,
you can find the answer in
[troubleshooting](https://hexo.io/docs/troubleshooting.html){target="_blank"
rel="noopener"} or you can ask me on
[GitHub](https://github.com/hexojs/hexo/issues){target="_blank"
rel="noopener"}. If you want to change the default theme of Hexo, please
check [Hexo Themes](https://hexo.io/themes/){target="_blank"
rel="noopener"}. An elegant theme would be the
[NEXT](https://github.com/theme-next/hexo-theme-next){target="_blank"
rel="noopener"}.
中文版详细入门教程可以点击[官网](https://hexo.io/zh-cn/docs/){target="_blank"
rel="noopener"} 和
[小白入门](https://godweiyang.com/2018/04/13/hexo-blog/){target="_blank"
rel="noopener"}。
